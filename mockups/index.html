Lunchline Deck — Design Directions

Click a card to view five sample slides per direction: Cover · Business Overview (KPI dashboard) · Investment Thesis · Investment Risks (multi-column table) · Value Creation Plan (chart + cards).

Direction 1
Institutional Classic

Pershing / Trian density. Confident, headline-driven, single-family sans-serif. Navy + red accent used only for thesis emphasis.

Font: Inter (one family, 3 weights)
Best for: Activist-flavored "things must change" thesis
Risk: Reads adversarial if pitch is pro-management
Direction 2 Recommended
Modern Operator

Stripe-meets-Greenlight. Serif body for prose, sans for data. Warm bone background reads as paper, not screen.

Fonts: Inter (display + data) + Source Serif 4 (prose)
Best for: Operator-investor persona Lunchline is testing for
Risk: Fonts must load cleanly; serif body slows skimming
Direction 3
Search Fund Minimal

IESE / GSB primer aesthetic. Maximum restraint, IBM Plex mono numbers, ~50% whitespace. One chart or table per page.

Fonts: IBM Plex Sans + Plex Mono (for numbers)
Best for: Specific-numbers thesis that needs to breathe
Risk: Dies if the analysis is thin — no design to hide behind

Mockups use a fictional small-cap ("Halcyon Interactive / HLYN") as placeholder content so design comes through without being confused for real analysis. Once a real company is picked, content swaps in via the same template. Slides are 1280×720 (16:9) — same aspect as PowerPoint.
