# HCKT Peer Selection Rationale

**As-of:** 2026-05-29. Multiples from stockanalysis.com (TTM, current-day EV) unless noted. All figures should be re-verified before use in a final deck; vendor EV figures occasionally mis-handle leases/contract liabilities.

## The comp problem
HCKT is a hybrid. The bear's whole case rests on tagging it as a commoditizing **IT-services / SAP-Oracle body shop** (→ EPAM at 6x EBITDA). The bull tags it as a **benchmarking-IP + AI-platform-enabled high-end advisory** firm (→ CRAI/FCN/EXLS at 10-13x). The right comp set spans both arenas, because *which arena HCKT belongs to is the entire thesis.* I therefore split the set:

### Arena 1 — High-end analytical / advisory consulting (the bull's tag)
- **CRAI (primary)** — litigation/economic/management consulting. Pure analytical-IP project advisory. 13.2x EBITDA / 1.54x rev. Demonstrates the market still pays a full multiple for analytical-consulting brains; this arena is *not* being de-rated for AI.
- **FCN (primary)** — restructuring/forensic/economic. Premium, diversified, counter-cyclical advisory. 12.1x EBITDA. Same message at larger scale.
- **HURN (primary)** — healthcare/education advisory + **digital/ERP implementation (Oracle/Workday)**. The single most structurally similar business: an advisory practice bolted to an ERP-implementation practice, exactly HCKT's Global S&BT + Oracle/SAP shape. 10.8x EBITDA / 1.46x rev is the best single read for a blended HCKT.

### Arena 2 — AI-enabled / digital-ops delivery (the pivot's destination)
- **EXLS (secondary)** — analytics + AI-enabled business-process management. The richest multiple in the set (2.2x rev, 12.7x EBITDA, 17% EBITDA margin) because the market *believes* its delivery is genuinely AI-levered. This is the upside multiple HCKT re-rates toward if its AI-platform delivery story is validated (the +500bps project-margin proof point).
- **ICFI (secondary)** — advisory + tech implementation, govt-heavy. Similar blend, 9.4x EBITDA, +5% LT growth. Different demand cycle (government), so secondary.

### The bear anchors (what de-rating looks like if the bear is right)
- **FORR (secondary, cautionary)** — syndicated research/advisory **subscription IP**. The market prices Forrester at ~**0.35x revenue** ($136M cap on $392M rev) on precisely the bear's thesis: that LLMs disintermediate syndicated research/benchmarking IP. This is the load-bearing-bear's real-world comp. The key distinction in the HCKT model: HCKT's IP is **process-execution / 28,400-study benchmark data embedded inside paid transformation delivery**, not a standalone syndicated-research subscription a CIO cancels for ChatGPT. If that distinction is wrong, HCKT de-rates toward FORR. If right, toward HURN/CRAI.
- **EPAM (excluded as primary)** — offshore digital-engineering / staff-aug. 6x EBITDA. The pure-body-shop floor multiple. Excluded from the core set because HCKT is not labor-arbitrage offshore engineering, but retained as the explicit **floor** if the market fully accepts the bear's "body shop" tag.

## How the multiples are used in the model
- **Blended fair multiple (base):** anchor on HURN/ICFI ~9.5-11x EBITDA, but on HCKT's **adjusted** EBITDA (~$56-60M), since the GAAP EBITDA is artificially depressed by the one-time stock-price-award SBC. HCKT's current ~6x adjusted EV/EBITDA is a ~40-45% discount to the HURN/CRAI/FCN advisory band.
- **Bear multiple:** EPAM-like 6x on a *lower, still-declining* adjusted EBITDA → tests the "it really is a melting body shop" case.
- **Bull multiple:** EXLS-like 10-12x if the AI-platform delivery re-rate is believed and revenue re-accelerates.
- **SOTP:** value Global S&BT (advisory/benchmark IP) on the CRAI/HURN advisory multiple, Oracle + SAP on the HURN-digital / ICFI implementation multiple, AI platforms (ZBrain/AI XPLR/Spend Matters JV) as separate optionality.

## Caveats
- HCKT's reported gross margin (yfinance 40.6%) is on a different basis than mgmt's "adjusted gross margin on revenue before reimbursements" (~44-46%); peer gross margins above are vendor TTM and not perfectly basis-aligned. EBITDA-multiple comparison is the more reliable cross-check than gross-margin levels.
- Forrester's vendor EV/EBITDA (2.86) looks distorted; only its EV/revenue (~0.35x) is used.
- Perficient (PRFT) — a natural ERP/digital-implementation comp — was taken private by EQT in 2024, so no current public multiple; its ~$3bn / ~12x take-out is a transaction data point that the AI-services-implementation arena commands strategic multiples.
