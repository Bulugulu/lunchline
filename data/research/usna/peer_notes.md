# USNA Peer Selection Rationale (methodology #3 — comp-proven)

## The valuation problem: USNA is two businesses with different comp sets
A single peer set is wrong. The SOTP requires two separate comp universes:

### Core Nutritional (declining MLM) — value off MLM/direct-seller peers
| Ticker | Why | EV/Rev | EV/EBITDA | Tier |
|---|---|---|---|---|
| **NUS** (Nu Skin) | Best fit: China-heavy, declining MLM (-12% rev), same secular pressure as USNA Core | ~0.29x | 3.05x | primary (bear anchor) |
| **HLF** (Herbalife) | Large MLM, but heavily levered — EV/Rev 0.59x is inflated by ~$3B debt; EV/EBITDA 4.81x cleaner | 0.59x | 4.81x | primary |
| **NATR** (Nature's Sunshine) | Closest by size/profitability ($384M cap, $490M sales, near net-cash, profitable, digital turnaround). EV/EBITDA 8.3x is the "stabilized direct-seller" ceiling | 0.78x | 8.3x | primary (upside anchor) |
| **MED** (Medifast) | Declining, loss-making weight-mgmt seller; P/S 0.42x; no EV/EBITDA (negative) | 0.42x | n/a | secondary (downside) |

Core implied EV/EBITDA from the MLM peer band: bear 3x (NUS) → base 4.5–5x (HLF) → bull 8x (NATR). USNA Core FY25 EBITDA ~$54M (EBIT $40.5M + Core D&A $13.5M). The DCF (below) lands inside this band, so I value Core on the DCF and use the peer band as the sanity check.

### Hiya (D2C children's-vitamin subscription) — value off the transaction + D2C VMS deals
| Anchor | Why | Multiple |
|---|---|---|
| **Hiya acquisition (Dec 2024)** | USANA paid $206.1M cash for 78.85% → implied 100% EV ~$261M on ~$130M rev = **~1.6x revenue / ~12x pre-amort EBITDA**. The single best, arm's-length, recent anchor. | 1.6x rev (BASE) |
| Put/Call mechanics | Remaining 21.15% repriced on **Hiya Adjusted EBITDA × a reference multiple**, puttable Apr-2028. Confirms parties value Hiya on an EBITDA multiple, not revenue. | — |
| Nutrafol (~$1B, Unilever), Olly (Unilever VMS roll-up), Bonafide ($425M, Pharmavite) | Strategics pay premium revenue multiples for D2C VMS brands with subscription/retention | 2–4x rev (deal comps) |
| **HIMS** (public D2C-subscription health) | EXCLUDED as a direct multiple (telehealth, +49% growth). Used only to bound the high end. Hiya is currently *shrinking* (subs 224k→186k YoY, rev -13% Q1'26), so the HIMS premium is explicitly NOT applied. | excluded |

Hiya range (v2, see model.md §A2): **bear 1.0x rev** → **base 1.5x** (transaction 1.6x haircut for soft quarters + staleness) → **bull 2.0x**. EBITDA cross-check: ~$20–22M pre-amort EBITDA × 8/10/12x corroborates.

## Honest caveat
Hiya's Q1 FY26 was *down* 13.3% YoY with subscribers off 17% as it pivoted from Meta-driven D2C to retail (Target/Costco) and ate CAC inflation. The 1.6x transaction anchor is 17 months stale and was struck before that softness. I therefore lean on the transaction as the *base*, not the *floor*, and let the 1.0x bear carry real weight.
